Linux x64: osslsigncode 2.14 built on Ubuntu 22.04 with GCC 11.4;
OpenSSL 3.0.2 (Ubuntu libssl-dev 3.0.2-0ubuntu1.30) and zlib 1.2.11
(Ubuntu zlib1g-dev 1:1.2.11.dfsg-2ubuntu9.2) are statically linked.
Only the system glibc/ELF loader remain dynamic dependencies.

macOS x64 / arm64: Homebrew osslsigncode 2.14 Sonoma bottles and matching
OpenSSL 3.6.3 bottles, minimum macOS 14.0. The original signed binaries
are preserved; the application sets DYLD_LIBRARY_PATH for the verifier
child process to use the included OpenSSL dylibs without Homebrew.
The Homebrew build formula (including its packaging-only patch) is in
../sources/homebrew-osslsigncode.rb. Native macOS execution and final
application signing/notarization have not been tested on this Windows host.

OpenSSL: Apache-2.0; see OpenSSL-LICENSE.txt and OpenSSL-Windows-LICENSE.txt.
zlib: see zlib-LICENSE.txt.

provenance.json. No private signing keys are distributed.
